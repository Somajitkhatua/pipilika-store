# CampusConnect - Final Year Minor Project Report

## Abstract
CampusConnect is a centralized web portal designed to streamline campus recruitment, student internships, hackathons, and placement management. It bridges the gap between students, recruiters, and college administrators with role-based access control, JWT authentication, and an AI-powered resume skill analyzer.

## Key Modules
1. **Student Module:** Profile management, resume upload, opportunity browsing & search, application tracking.
2. **Recruiter Module:** Company profile, posting internships/jobs, applicant review and shortlisting.
3. **Admin Module:** User management, recruiter verification, platform statistics.
4. **AI Resume Matcher:** Automated skill extraction and matching percentage calculator comparing student skills with job requirements.

## Conclusion
CampusConnect successfully demonstrates Java Full Stack proficiency using Spring Boot, Spring Security, MySQL, and modern responsive frontend engineering.
